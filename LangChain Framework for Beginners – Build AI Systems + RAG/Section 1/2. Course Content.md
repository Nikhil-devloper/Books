# Chapter 2: LangChain Course Overview — What You Will Learn

## 1. AI Agents — Fundamentals
- Understanding agent architecture
- Creating agents using `createAgent()`
- Agent invocation and message passing
- Tool-based agent workflows
- Model selection (GPT-4, Claude Sonnet)

## 2. Tools & Function Calling
- Creating custom tools using `tool()`
- Zod validation schemas
- Multi-tool orchestration
- Practical examples:
  - `getWeather`
  - `getTime`
  - `emailTool`
  - `searchTool`

## 3. System Prompts & Prompt Engineering
- Custom `systemPrompt`
- `dynamicSystemPromptMiddleware` — injecting dynamic context into system prompts

## 4. Context Management
- Using `config.context` for user-specific data
- Managing environment configurations

## 5. Memory & State Management
- `MemorySaver` checkpointer
- Understanding `thread_id` handling
- Maintaining persistent conversation history

## 6. Structured Outputs
- Using `responseFormat`
- Defining Zod schemas
- Generating type-safe responses

## 7. Model Configuration
- Initializing models using `initChatModel()`
- Configuring temperature, timeouts, and token limits
- Supporting multiple models

## 8. Middleware System
- `dynamicModelSelection`
- `modelFallbackMiddleware`
- `summarizationMiddleware`
- `llmToolSelectorMiddleware`
- `piiRedactionMiddleware`

## 9. Guardrails & Safety
- Personally Identifiable Information (PII) detection
- Regex-based filtering
- Compliance patterns

## 10. Retrieval-Augmented Generation (RAG)
- Loading PDF and DOCX documents
- Text splitting: 1,000-character chunks with 200-character overlap
- Embeddings using `text-embedding-3-large`
- Using `MemoryVectorStore`
- Similarity search and Maximal Marginal Relevance (MMR)
- Implementing RAG through middleware and tools

## 11. Multi-Tool Agents
- Combining RAG with utility tools
- Multi-domain orchestration
- Coordinating multiple tools to complete a task

## 12. MCP Integration — Agentic RAG
- Using `MultiServerMCPClient`
- Integrating external systems with RAG
- Connecting agents to external tools and services through the Model Context Protocol (MCP)

## 13. LangGraph Deployment
- Understanding `langgraph.json`
- Working with `ragagentServer.ts`
- Preparing an agent application for deployment

## 14. Environment Management
- Managing API keys securely
- Using `.env` files
- LangSmith tracing and observability

---

## Learning Goal

By the end of this course, the goal is to understand how to build an AI agent application that can:

- Reason about user requests and select appropriate tools.
- Retrieve information from documents using RAG.
- Maintain conversation history and manage state.
- Produce structured, type-safe outputs.
- Apply middleware, validation, and safety controls.
- Integrate external systems through APIs and MCP.
- Trace, debug, and deploy agent applications.

**Important:** This is the course roadmap, not a list of concepts already mastered. Each topic should be understood and practiced as you progress through the tutorial.
